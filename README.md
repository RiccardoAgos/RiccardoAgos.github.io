# Portfolio di Riccardo Agostini

Portfolio personale sviluppato con React e Vite. Presenta il profilo
professionale, i contatti e ExpenseMate, applicazione mobile pubblicata su iOS.

## Sviluppo locale

```bash
npm install
npm run dev
```

## Build di produzione

```bash
npm run build
```

I file statici pronti per la pubblicazione vengono generati nella cartella
`dist`. Per un hosting tradizionale come IONOS, va caricato il contenuto di
questa cartella nella directory pubblica del dominio.
